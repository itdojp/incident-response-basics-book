# タイムラインテンプレ

## 時刻の記入ルール

- 推奨: タイムゾーン付き（RFC3339 形式）（例: `2026-02-24T10:12:00+09:00`）
- 最低限: JST/UTC を明記（例: `10:12 JST`）

複数ログ源を相関する場合は、表記だけでなく時刻同期と時計ずれを確認する。原ログの時刻は上書きせず、補正する場合はタイムラインに原時刻と補正後時刻を併記する。同期状態や時計ずれが不明な場合は「不明」と記録し、時刻だけで事象の順序を確定しない。

## 時刻整合性

- 共通タイムソース / 基準時刻:
- 確認日時（タイムゾーン付き）:
- ログ源ごとの同期状態（同期済み / 未同期 / 不明）:
- 確認した時計ずれ（ログ源、基準との差、方向）:
- 補正（なし / あり。対象、幅・方向、根拠）:
- 原時刻の保全先:

## 記入例（抜粋）

- 時刻整合性: アプリは共通タイムソースへの同期済み、DB は同期状態不明（確認日時: `2026-02-24T10:20:00+09:00`）
- 確認した時計ずれ: DB は基準より 2.4 秒進み
- 補正: DB の分析用時刻を -2.4 秒補正。原ログは証跡 `EVIDENCE-20260224-DB-01` に保全
