## 記入例（最小）

- 事象: API の 5xx 増加
- 影響: 一部リクエスト失敗
- Severity: 暫定 P1
- セキュリティ/プライバシー疑い: 未判断
- ステータス: 暫定対応中
- 観測事実: 10:12 JST から 5xx が増加
- 仮説: 直近デプロイにより DB 接続待ちが増加
- 証跡: 10:00〜10:30 JST の API ログとメトリクスを保全（情報分類: 本番ログ、マスク済み）
- 次アクション: 直近変更の確認→ロールバック判断
