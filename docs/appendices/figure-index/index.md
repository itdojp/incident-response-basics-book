## 使い方

1. 現在の対応段階に近い図を選ぶ。
2. 本文の文章による代替説明と判断基準を読む。
3. テンプレートまたはチェックリストへ判断根拠と次アクションを記録する。

図の流れが組織の権限、契約、法令、セキュリティ手順と異なる場合は、組織の正式手順を優先してください。
